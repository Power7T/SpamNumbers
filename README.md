# 📵 Spam-Numbers Enterprise Intelligence Grid

An elite OpenClaw OSINT skill designed for 24/7 global spam detection, autonomous search exploration, and real-time threat intelligence.

## 🚀 Key Features
- **17+ Global OSINT Scrapers**: Parallel extraction from Tellows, SyncMe, Nomorobo, FTC, and community forums.
- **Autonomous AI Hunt**: Machine-learning driven web search (Reddit/Twitter/Forums) to discover new scam vectors.
- **Historical Deep-Crawl**: Forensic archive scanner that recovers 100,000+ aged-out threat signatures.
- **Elite Glassmorphism Dashboard**: Modern Cyber-Industrial UI for live monitoring, global search, and manual threat injection.
- **Permanent Storage**: Every discovered number is stored indefinitely with no score decay.
- **Auto-Download CSV**: One-click database exports that automatically download to your local PC from the VPS.

## 🛠️ Usage (CLI / TUI)
Respond with "spam" in the OpenClaw chat to see the full capability list.

| Command | Description |
|---|---|
| `full-scan` | **🔥 Master Defense Sequence**: Sequential execution of all scanners & cleanup. |
| `scrape` | Standard global OSINT sweep. |
| `hunt` | Autonomous AI-driven OSINT hunt. |
| `deep-crawl` | Recover historical records from community archives. |
| `lookup <num>` | Instant real-time database check for a specific target. |
| `delete <num>` | Permanently scrub a number from the grid. |

## 🌐 Dashboard Access
The dashboard runs by default on **Port 5555**. 
To access it from your browser:
1.  **Open Port 5555**: Ensure your VPS provider (e.g. Azure, Contabo) has an Inbound Firewall Rule for TCP 5555.
2.  **Navigate to**: `http://<vps-ip>:5555`
